# 🛡️ TenderGuard — Smart Tender Fraud Risk Detection System

**TenderGuard** is an advanced AI-powered procurement intelligence and fraud risk detection platform. It uses graph-based relational modeling, co-bidding analysis, price proximity clustering, and Graph Neural Network (GNN) heuristics to uncover cartel formations, bid rigging, and suspicious bidding syndicates in public tenders.

---

## 🌟 Key Features

- **📊 Central Executive Dashboard**: Real-time portfolio metrics, live database statistics, and interactive pattern intelligence.
- **📑 Tender Registry & Bid Management**: Full lifecycle management of public notices, bidder entries, quoted prices, and award history.
- **🏢 Companies & Contractor Directory**: Bidder relationship tracking, participation history, and win/loss analytics.
- **🔍 Historical Pattern Analysis**:
  - Repeated co-bidding pair detection across multi-year procurement histories.
  - Quoted price proximity clustering (identifies bids differing by $\le 5\%$).
  - Alternating winner rotation detection (uncovers cartel bid rotation).
  - Empirical win rates and participation frequencies.
- **🤖 Deterministic AI Risk Engine**:
  - Evidence-based 0–100 **Suspicion Score** (Low, Moderate, High, Very High).
  - Explainable AI breakdown: *"Why was this flagged?"* with concrete mathematical and relational evidence.
  - Deep Learning architecture ready for inductive node representation learning over bipartite procurement graphs.
- **🚨 Oversight Alerts & Triage**:
  - Automated alert dispatching on high-suspicion events.
  - Auditor workflow for reviewing, triaging, and recording timestamped investigation notes.
- **📋 Forensic Audit Reports**:
  - Detailed procurement dossiers with complete evidence breakdown, printable layout (**Print to PDF**), and legal disclaimers.
- **⚙️ Configurable Platform Settings**:
  - Live sensitivity controls (Price delta %, minimum co-bidding threshold, alert triggers).
  - Database connectivity telemetry and auditor credential management.

## 🏗️ Architecture & Tech Stack

### **Backend**
- **Framework**: FastAPI (Python 3.10+)
- **ORM / Database**: SQLAlchemy 2.0 with PostgreSQL (and SQLite dev fallback)
- **AI & Graph Engine**: NetworkX, PyTorch / GNN architecture (`ProcurementGraphSAGE`)
- **Security**: JWT Authentication, bcrypt password hashing, Role-Based Access Control (RBAC)

### **Frontend**
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS (Deep Forest Green & Sandal Warmth design system)
- **Icons**: Lucide React
- **State & Routing**: Single Page Architecture with secure Auth Context

## 🚀 Getting Started

### **One-Click Launch (Windows)**
Simply double-click:
```cmd
run.bat
```
This automatically launches both the FastAPI backend and Vite frontend and opens your browser.

---

### **Manual Launch**

#### **1. Start Backend**
```powershell
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```
- API Docs: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

#### **2. Start Frontend**
```powershell
cd frontend
npm run dev
```
- Web Application: [http://localhost:5173](http://localhost:5173)
